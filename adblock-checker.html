❓ FAQ

How it works? The test tries to load resources from known ad/tracker domains and checks if they are blocked.

Cosmetic filter: we insert elements with classes commonly blocked (adsbygoogle, advertisement) and check if they are hidden.

Script loading: attempts to load real ad scripts (Google AdSense, DoubleClick). If they fail, it's blocked.

Host blocking: image requests to known ad/tracker domains. If the request fails, it's blocked.

Score: percentage of blocked items across all tests.
