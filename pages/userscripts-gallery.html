UserScripts Gallery

Collection of useful UserScripts for enhancing web browsing

How to Use

  1. Install a userscript manager like Tampermonkey or Violentmonkey
  2. Click Copy Code to copy the script to clipboard
  3. Click the Add Script button in your userscript manager
  4. Paste the code and click Save
  5. The script will automatically run on the specified websites
