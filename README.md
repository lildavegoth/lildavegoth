Kakoi Kiraku is my evolving website system designed to deliver the latest tools, resources, and inspiration directly to you.
All apps run entirely in the browser with a strong focus on **privacy** and **simplicity** — many process data locally without sending anything to a server.

New apps and games are added regularly, so be sure to check back often!
